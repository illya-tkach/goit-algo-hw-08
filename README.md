# goit-algo-hw-08

Домашнє завдання до тем 7–8 «Дерева та балансування», «Купи».

## Структура

| Файл | Опис |
|---|---|
| `avl_tree.py` | Реалізація AVL-дерева (вставка з балансуванням) |
| `task1.py` | Завдання 1 — пошук найменшого значення в дереві (`find_min`) |
| `task2.py` | Завдання 2 — сума всіх значень у дереві (`tree_sum`) |
| `task3.py` | Завдання 3 — мінімальні витрати на з'єднання кабелів за допомогою купи (`min_connection_cost`) |

## Запуск

```bash
python3 task1.py
python3 task2.py
python3 task3.py
```

## Рішення

- **Завдання 1.** У двійковому дереві пошуку мінімум знаходиться в найлівішому вузлі — йдемо ліворуч від кореня. Складність O(log n) для AVL-дерева.
- **Завдання 2.** Рекурсивний обхід: значення вузла + сума лівого + сума правого піддерева. Складність O(n).
- **Завдання 3.** Жадібний алгоритм на мінімальній купі (`heapq`): щоразу з'єднуємо два найкоротші кабелі й кладемо результат назад у купу. Складність O(n log n).
  Приклад: `[4, 3, 2, 6]` → `2+3=5`, `4+5=9`, `6+9=15` → загальні витрати **29**.
